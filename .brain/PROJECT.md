# Project

Name: Stockfish Chess Academy

Purpose: A production-style chess web app where users can play Stockfish and learn chess through interactive beginner lessons.

Stack:
- React 18
- Vite
- JavaScript and JSX only
- chess.js for rules
- stockfish npm package, served as a browser worker asset
- React Router
- lucide-react icons
- CSS variables and plain CSS

This project uses JavaScript and JSX. TypeScript is NOT used. Do not introduce .ts or .tsx files.

Routes:
- /
- /play
- /learn
- /learn/basics
- /learn/pieces
- /learn/movement
- /learn/capturing
- /learn/check
- /learn/checkmate
- /learn/castling
- /learn/en-passant
- /learn/promotion
- /learn/tactics

Status: Initial app implemented. Build passes. Main routes return HTTP 200 in Vite preview.
