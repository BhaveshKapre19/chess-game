# Changelog

## 1.0.0

- Created Vite React chess app.
- Added board, move validation, highlights, promotion dialog, move history, captured pieces, settings, and result modal.
- Added Stockfish 16 worker integration through a dedicated engine abstraction.
- Added Learn dashboard, reusable interactive lesson board, hints, feedback, and local progress tracking.
- Added responsive visual design system.
- Added .brain project memory.

## 1.0.1

- Replaced Unicode board pieces with reusable SVG chess pieces.
- Restyled the playable board with a classic green chess.com-inspired palette.
- Updated promotion and captured-piece displays to use the same SVG pieces.

## 1.0.2

- Improved SVG piece contrast, especially white pieces on light squares.
- Reworked bishop and knight SVG silhouettes for clearer recognition.
